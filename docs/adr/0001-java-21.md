# ADR-0001: Java 21 as the only backend language

- Status: Accepted

## Question
Is Java (owner's suggestion) a good backend language for a local PDF generator?

## Decision
Yes: Java 21 LTS, Maven build (`mvn verify`), no preview features.

## Rationale
- Owner suggested it and knows some Spring; JDK 21 + Maven are already installed.
- `record`s, sealed interfaces and pattern-matching `switch` fit an immutable, typed document model.
- Mature, pure-Java, offline libraries exist for everything needed (OpenHTMLtoPDF, PDFBox, ZXing).
- Static typing makes refactoring safe for a single maintainer.

## Alternatives considered
- **Python + WeasyPrint**: excellent CSS support, but needs GTK/Pango on Windows; weakest stack for the owner.
- **Node/TS + Puppeteer**: familiar, but drags in a browser dependency and gives a weaker typed domain.
